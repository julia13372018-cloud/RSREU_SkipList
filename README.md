# RSREU_SkipList

## Курсовая работа по дисциплине "Алгоритмы и структуры данных"

**Авторы:** 
Яковенко Юлия, гр. 5413
Жалненков Николай, гр. 5413

**Тема:** Проектирование структуры данных «список с пропусками» (Skip List) и её использование для решения прикладных задач


## Описание

Реализовать структуру данных Skip List (список с пропусками) для операций поиска, вставки и удаления элементов. Приложение должно позволять вводить элементы, визуализировать многоуровневую структуру списка, демонстрировать процесс поиска (движение по «экспресс-уровням» и спуск вниз) и процесс вставки с вероятностным «повышением» узла. Предусмотреть настройку параметров (например, вероятность повышения уровня p=1/2 или 1/4) и пошаговый режим.

### Акценты:

**Глава 1:** вероятностная природа структуры (генерация уровней при вставке). Доказательство математического ожидания сложности O(log n) для поиска/вставки/удаления. Сравнение с детерминированными сбалансированными деревьями (AVL, Красно-черные) с точки зрения сложности реализации и асимптотики.

**Глава 2:** архитектура приложения. Визуализация многоуровневого связного списка (отрисовка узлов и указателей на разных уровнях). Анимация процесса поиска (подсветка пути) и вставки (показ «подбрасывания монетки» и роста узла).

**Глава 3:** тестирование на массивах данных от 10³ до 10⁶ элементов. Сравнение производительности с обычным связным списком и сбалансированным деревом поиска (AVL). Применение в реальных системах (например, в Redis для Sorted Sets или LevelDB), анализ причин выбора Skip List в этих системах.
